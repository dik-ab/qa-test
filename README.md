# QAマッチングテスト - ファイルからクエスチョンデータ生成システム

PDFファイルや画像ファイルから自動的にQ&A（質問と回答）データを生成し、CSV/XLSX形式でエクスポートできるNext.jsアプリケーションです。AWS Bedrock（Claude 3.5 Sonnet）を使用してAIによる高品質なQ&Aデータを生成します。

## 🚀 主な機能

### ファイル処理機能
- **PDFファイル解析**: 複数のPDFファイルからテキストを抽出し、内容を解析
- **画像ファイル解析**: OCR（Tesseract.js）を使用して画像からテキストを抽出
- **複数ファイル対応**: 一度に複数のファイルをアップロードして一括処理

### AI駆動のQ&A生成
- **AWS Bedrock統合**: Claude 4 Sonnetモデルを使用した高品質なQ&A生成
- **カスタマイズ可能な質問数**: 1〜10個の質問を生成可能
- **具体的で実用的な質問**: 文書の重要な情報を基にした詳細な質問を生成
- **丁寧で正確な回答**: 敬語を使用した分かりやすい回答を生成
- **プロンプト編集機能**: ユーザーがAIプロンプトをカスタマイズして質問生成をコントロール可能

### プロンプトカスタマイズ機能
- **リアルタイム編集**: 直感的なUIでプロンプトを編集
- **変数置換**: `${text}`と`${numQuestions}`変数の自動置換
- **デフォルト復元**: ワンクリックでデフォルトプロンプトに戻す機能
- **カスタム状態表示**: カスタムプロンプト使用中の視覚的フィードバック
- **一時的な検証**: カスタムプロンプトでの質問生成をテスト可能

### データエクスポート機能
- **CSV形式**: Excel互換のCSVファイルとしてエクスポート
- **XLSX形式**: Excelファイルとして直接エクスポート
- **タイムスタンプ付きファイル名**: 自動的に日時を含むファイル名を生成

```bash

```

### 2. 依存関係のインストール
```bash
npm install
# または
yarn install
```

### 3. 環境変数の設定
プロジェクトルートに `.env.local` ファイルを作成し、以下の環境変数を設定してください：

```env
AWS_REGION=us-east-1
AWS_ACCESS_KEY_ID=your_access_key_id
AWS_SECRET_ACCESS_KEY=your_secret_access_key
```

### 4. 開発サーバーの起動
```bash
npm run dev
# または
yarn dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてアプリケーションにアクセスできます。

## 📖 使用方法

### 基本的な使い方

1. **プロンプト設定（オプション）**
   - 「プロンプト編集」ボタンをクリックしてAIプロンプトをカスタマイズ
   - デフォルトプロンプトを使用する場合はこの手順をスキップ

2. **ファイルタイプの選択**
   - 「PDFファイル」または「画像ファイル」タブを選択

3. **ファイルのアップロード**
   - 「ファイルを選択」ボタンをクリック
   - 対応ファイル形式を選択（複数選択可能）

4. **質問数の設定**
   - スライダーで生成する質問数を1〜10個で設定

5. **Q&Aデータの生成**
   - 「ファイルからクエスチョンデータを生成」ボタンをクリック
   - AIが自動的にQ&Aデータを生成

6. **データのエクスポート**
   - 「CSV」または「XLSX」ボタンでファイルをダウンロード

### プロンプト編集機能の使い方

#### プロンプトの編集
1. **編集画面を開く**
   - 「プロンプト編集」ボタンをクリック
   - モーダルダイアログが開きます

2. **プロンプトをカスタマイズ**
   - テキストエリアでプロンプトを自由に編集
   - `${text}` と `${numQuestions}` 変数が利用可能
   - リアルタイムで変更内容を確認

3. **変更を保存**
   - 「保存」ボタンで変更を適用
   - カスタムプロンプト使用中の表示に変わります

#### 利用可能な変数
- **`${text}`**: アップロードされたファイルから抽出されたテキスト
- **`${numQuestions}`**: 設定された質問数

#### プロンプトの復元
- **デフォルトに戻す**: 「デフォルトに戻す」ボタンでオリジナルプロンプトに復元
- **復元アイコン**: カスタムプロンプト使用中に表示される復元アイコンをクリック

### 対応ファイル形式

#### PDFファイル
- `.pdf` 形式のファイル
- 複数ファイルの同時処理に対応

#### 画像ファイル
- JPEG (`.jpg`, `.jpeg`)
- PNG (`.png`)
- GIF (`.gif`)
- BMP (`.bmp`)
- WebP (`.webp`)

## 🆘 トラブルシューティング

### よくある問題

1. **AWS Bedrock接続エラー**
   - AWS認証情報が正しく設定されているか確認
   - Bedrockサービスへのアクセス権限を確認

2. **PDFテキスト抽出の失敗**
   - PDFファイルが破損していないか確認
   - ファイルサイズが適切な範囲内か確認

3. **画像OCRの精度が低い**
   - 画像の解像度を上げる
   - 文字がはっきりと見える画像を使用

4. **カスタムプロンプトが機能しない**
   - プロンプト内に `${text}` と `${numQuestions}` 変数が含まれているか確認
   - JSON出力形式の指示が含まれているか確認

### パフォーマンス最適化

- 大きなファイルは事前に分割することを推奨
- 同時処理するファイル数を制限
- 生成する質問数を適切に設定
- カスタムプロンプトは簡潔で明確な指示を心がける

### プロンプト編集のベストプラクティス

- **明確な指示**: AIに対して具体的で明確な指示を与える
- **出力形式の指定**: JSON形式での出力を明示的に指定
- **変数の活用**: `${text}` と `${numQuestions}` を適切に使用
- **例示の提供**: 期待する質問と回答の例を含める
